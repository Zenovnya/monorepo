# Supabase (PostgreSQL)

Supabase используется как управляемый PostgreSQL для backend'а.

- **Пошаговая инструкция:** [`DEPLOY.md`](DEPLOY.md).
- **Формат строки подключения:** возьмите URI в *Project Settings → Database →
  Connection string* и замените схему на `postgresql+asyncpg://`.
- **Пул соединений:** для приложения берите порт `6543` (PgBouncer, transaction
  mode) и добавляйте `?prepared_statement_cache_size=0` — asyncpg несовместим с
  серверным кэшем подготовленных выражений в этом режиме. Для миграций
  (`alembic upgrade head`) используйте прямое подключение (порт `5432`):
  PgBouncer не держит часть DDL-сессий.

## Что важно помнить

- Каскадные удаления (`ON DELETE CASCADE`) реально работают только в Postgres.
  На sqlite внешние ключи по умолчанию выключены, поэтому `delete_account`
  подметает связанные записи вручную — это не дублирование логики, а обход
  различия диалектов.
- Backup'ы на бесплатном тарифе ограничены: перед миграциями с удалением
  данных сделайте дамп вручную.
