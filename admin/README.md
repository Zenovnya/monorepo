# LexBear — Админка контента

Управление учебным контентом (юниты, уроки, теория, вопросы, кейсы, статьи)
без правки кода и без пересборки приложения.

## Как это устроено

Мобильное приложение и админка — два клиента к одному backend'у и одной БД:

- **Мобилка** (React Native) читает контент через `/lexbear/*`.
- **Админка** (веб-страница) пишет контент через `/admin/content/*` (под токеном).

Правки видны в приложении сразу: после любой записи инвалидируется кэш чтений.

## Где открыть админку

Backend сам отдаёт страницу — отдельный сервер не нужен:

```
https://<адрес-вашего-API>/admin/ui
```

Открой в браузере на компе, вставь **admin-токен** (см. ниже) — и работай.
Страница обращается к API с того же адреса, поэтому CORS настраивать не нужно.

## Настройка доступа

Задай переменную окружения backend'а:

```
ADMIN_TOKEN=<длинная-случайная-строка>
```

Без неё админ-эндпоинты закрыты в production (в `DEBUG=true` — открыты для
локальной разработки). Токен передаётся страницей в заголовке `X-Admin-Token`.

## Два способа управлять контентом

### 1. Через форму (для точечных правок, без редеплоя)
Вкладки «Кейсы» и «Уроки»: добавляй/редактируй/скрывай мышкой. Пишется прямо
в БД. Удаление — **мягкое** (`is_active=false`): контент скрывается от
пользователей, но прогресс и история повторений (SRS) сохраняются.

### 2. Через JSON-паки (для массового наполнения, версионируется в git)
Файлы на сервере: `backend/app/content_packs/`
- `curriculum.json` — юниты → уроки → теория/вопросы
- `cases.json` — кейсы
- `articles.json` — справочные статьи

Отредактируй файлы (ключи: `code` у юнитов/статей, `slug` у уроков/кейсов),
задеплой, затем на вкладке «Загрузка из JSON» нажми **Запустить загрузку**.
Опция **prune** деактивирует то, чего больше нет в файлах.

## API (для скриптов/CI)

```
POST   /admin/content/reload?prune=false      # загрузка из JSON-паков
GET    /admin/content/cases                    # список кейсов
PUT    /admin/content/cases                    # upsert кейса (по slug)
DELETE /admin/content/cases/{slug}?hard=false  # мягкое/жёсткое удаление
GET    /admin/content/units
GET    /admin/content/lessons
PUT    /admin/content/units/{unit_code}/lessons  # upsert урока (по slug)
DELETE /admin/content/lessons/{slug}
```

Все требуют заголовок `X-Admin-Token`.
