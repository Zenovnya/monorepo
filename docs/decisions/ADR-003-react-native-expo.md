# ADR-003: React Native + Expo для мобильного клиента

**Статус:** принято · **Дата:** 2026-10

## Контекст

Приложение нужно на iOS и Android одновременно, силами небольшой команды,
которая уже знает React (веб-админка на JS). Дизайн насыщен анимациями
(хохломские орнаменты, мишка с мимикой, пружинные нажатия), есть deep links
(сброс пароля, возврат из оплаты) и push. Сроки — MVP, магазины приложений —
цель.

## Решение

- **React Native + Expo (SDK 54)**, сборка через EAS.
- **React Navigation** — стек + табы, deep linking.
- **TanStack Query** — серверные данные, кэш, инвалидация.
- **Zustand** — сессия и пользователь.
- **Reanimated** — анимации на UI-потоке.

## Почему

1. **Один код на две платформы** при знакомом стеке: команда не учит Swift и
   Kotlin, веб-админка и приложение говорят на одном языке.
2. **Expo закрывает инфраструктуру**: сборки, OTA-обновления, push-токены,
   `expo-haptics`, `expo-notifications`, deep links — без нативной возни.
3. **Reanimated вместо `Animated`.** Для интерфейса, где нажатий десятки,
   JS-поток не годится: анимации считаются на UI-потоке, жесты не рвутся при
   загрузке данных. Всё уважает `useReducedMotion`.
4. **TanStack Query вместо Redux-хранилища серверных данных.** Данные сервера
   — не состояние приложения: их нужно кэшировать, инвалидировать и
   перезапрашивать при возврате связи, а не синхронизировать руками.
5. **Zustand, а не Redux.** Состояния мало (сессия, пользователь, одноразовое
   уведомление); бойлерплейт Redux не окупается.

## Следствия

- **Сборки через EAS**, не локальный `xcodebuild`: профили в `mobile/eas.json`,
  инструкция — `mobile/EAS_DEPLOY.md`.
- **Нативные модули только через Expo-плагины.** Своего нативного кода нет:
  это сохраняет OTA-обновления и простые сборки.
- **Веб-версия — побочный продукт** (`expo export --platform web`): ею
  пользуются для просмотра интерфейса, продуктом она не считается. Некоторые
  вещи на вебе ведут себя иначе — например `Alert.alert` молчит, поэтому
  важные сообщения идут через стор и собственные экраны.
- **Размер бандла** растёт (Reanimated, иконки, шрифты), поэтому тяжёлые
  assets грузятся лениво, а ответы API сжаты gzip.
- **Клиент — тонкий**: результаты урока, остаток жизней, XP считает сервер.
  Локальные счётчики существуют только для мгновенного отклика и
  синхронизируются с сервером.

## Рассмотренные альтернативы

| Вариант | Почему нет |
|---|---|
| Два нативных приложения (Swift + Kotlin) | Двойная работа при маленькой команде; дизайн-система дублировалась бы |
| Flutter | Отличный выбор, но команда на React; Dart — новый язык и экосистема |
| PWA вместо приложения | Нет нормального push на iOS, нет магазинов, ограниченные жесты и анимации |
| Expo + собственный нативный код | Потеря OTA и усложнение сборок без текущей необходимости |
