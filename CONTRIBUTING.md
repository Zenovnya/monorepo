# Как вносить изменения

## Что где лежит

```
backend/        FastAPI-сервис, app/modules/<домен>, миграции, тесты
mobile/         Expo-приложение (src/api, src/screens, src/components)
admin/          веб-админка контента (отдаётся на /admin/ui)
infra/          docker-compose, railway, supabase
docs/           продукт, архитектура, БД, API, решения (ADR)
scripts/        ci-smoke.sh, send-reminders.sh, dev-*.ps1
```

Правила доменов: новый код кладётся в модуль
`backend/app/modules/<домен>/{models,schemas,service,routes}.py`; роут не
содержит бизнес-логики — она в сервисе и тестируется без HTTP.
Мобильный API-слой (`mobile/src/api/*`) повторяет структуру модулей.

## Локальный запуск

Полный порядок — в [`README.md`](README.md) (Docker, локальный Postgres,
Windows-скрипты) и [`docs/LOCAL_DEV_TESTING.md`](docs/LOCAL_DEV_TESTING.md)
(включая запуск с телефона в локальной сети).

## Перед коммитом

```bash
# backend
cd backend
python -m pytest                 # тесты
python -m ruff check app tests   # линт

# mobile
cd mobile
npm run lint
```

`python -m pytest` требует `JWT_SECRET_KEY` (≥32 символов). Тесты на sqlite
отдельных фикстур не требуют: они сами поднимают схему через
`Base.metadata.create_all`.

## Правила, за которые уже платили баги

- **Дефолты SQLAlchemy применяются только при INSERT.** До `flush` числовое
  поле равно `None`; `default=` не спасает от `None + 1`. Числовые поля задавай
  явно при создании объекта, а для моделей с важными флагами добавляй
  `__init__` (см. `NotificationSettings`, `Subscription`).
- **Новая таблица с `user_id`** должна иметь `ON DELETE CASCADE`: иначе данные
  переживут удаление аккаунта. Это проверяет
  `tests/test_user_account.py::test_user_owned_models_cover_progress_and_tokens`.
- **Миграция обязательна для любого изменения модели.** В CI нет второго
  Postgres, поэтому проверяй ревизию на sqlite через `MigrationContext` +
  `Operations` (пример — в истории PR про `0020`/`0023`).
- **Клиент не считает результаты.** Ответы уходят на сервер, сервер сверяет с
  эталоном (`content/lexbear_scoring.py`). Клиентский счёт — только для UI.
- **Ошибки — для людей.** В `detail` русский текст, а если клиенту нужны
  данные — объект (`409 {"code": "no_lives", ...}`). Никаких `error.message`
  на экранах: есть `describeLoadError` и `StateViews`.
- **Внешние интеграции не роняют бизнес-операцию.** Сбой Expo, Resend или
  шлюза логируется и попадает в отчёт, но урок не падает.
- **Контент — данные, а не код.** Кейсы/уроки правятся в
  `backend/app/content_packs/*.json` и импортируются идемпотентно. Импорт не
  равен юридической проверке: до `approved` кейс не показывается
  (`docs/legal-content-policy.md`).
- **Не трогай `AnimatedMascot.js` без причины**: в нём 4 известных
  предупреждения `react-hooks/exhaustive-deps`, они осознанны.

## Коммиты и PR

- Сообщение коммита отвечает на «что и почему сломалось», а не «какие файлы
  изменены». Если правка исправляет дефект — в тексте есть симптом, который
  видел пользователь.
- Один PR — одна законченная тема. Изменение поведения без теста требует
  объяснения в описании PR.
- В описании PR: что было сломано, что сделано, как проверено (числа тестов,
  линтеры, сборка), что осталось открытым. Последнее — обязательно: скрытая
  незакрытая часть опаснее честно названной.
- Мержим только при зелёном CI: `Tests (pytest)`, `Lint (ruff)`,
  `Lint (mobile)`, `Dependency audit`, `Security & Lint`.

## Миграции: порядок

```bash
cd backend
# 1) изменил модель
# 2) написал миграцию вручную: migrations/versions/00NN_<тема>.py
# 3) проверил upgrade и downgrade на sqlite
# 4) alembic upgrade head на реальном Postgres (staging или локальном)
```

`down_revision` всегда указывает на предыдущую ревизию; имя файла — `00NN`
и короткая тема по-английски.

## Стиль

- Комментарий объясняет **почему**, а не что: «раньше здесь был тупик без
  действия» полезнее, чем «рисуем кнопку».
- Русский язык в пользовательских текстах и комментариях, английский — в
  именах кода.
- Не добавляй зависимость ради одной функции: в backend список короткий и
  проверяется `pip-audit`.
